## Архитектура

Проект состоит из двух микросервисов:

### **Generator (FoodCards)**
- Порт: `90`
- Генерация тестовых данных
- Отправка файлов в Receiver через:
  - gRPC (порт 6666)
  - REST API (порт 666)
  - Chunked upload

### **Receiver**
- HTTP порт: `666`
- gRPC порт: `6666`
- Приём и обработка файлов
- Сохранение в БД:
  - PostgreSQL (порт 5434)
  - Oracle (порт 1521)

## Требования

- Docker и Docker Compose
- Java 21 (для локальной разработки)
- Gradle 8.7+
